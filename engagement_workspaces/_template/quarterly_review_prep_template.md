# Quarterly Review Prep — [ENGAGEMENT CODE] [YYYY Q#]

Template for preparing a single quarterly review session. Copy this
file to `quarterly_review_<YYYY>Q<#>.md` for each review (e.g.
`quarterly_review_2026Q1.md`).

The prep document is for the consultant. Some sections become talking
points in the review; others are consultant-only notes for staying
oriented.

## Pre-review preparation checklist

Use this list to verify everything is ready before walking into the
review:

- [ ] Findings status (`findings_status.md`) is current
- [ ] Action items from previous review (`action_items.md`) have
      been checked for status
- [ ] Methodology evolution notes (`methodology_evolution_notes.md`)
      have been reviewed for items relevant to this review
- [ ] Engagement-specific Aletheia diagnostic has been re-run on
      the current corpus, and the new findings have been triaged
      into `findings_status.md`
- [ ] Communications since last review (`communications_log.md`)
      have been read for context
- [ ] Pricing / retainer status is current per
      `engagement_overview.md`
- [ ] If methodology version changed since last review, the
      `release_procedure.md` has been followed and the deployment
      record is up to date

## Agenda (consultant-facing)

1. **Status of action items from last review** (5 min)
2. **Findings status update** (15 min)
3. **Methodology updates since last review** (10 min, if applicable)
4. **New findings from latest diagnostic run** (15 min, if any)
5. **Methodology-evolution discussion** (10 min)
6. **Forward-looking action items and next-quarter focus** (15 min)
7. **Open questions / scope conversations** (open-ended)
